# CustomerChurnAI — Customer Churn Prediction

A Machine Learning project that predicts customer churn using Python, Scikit-learn, and Streamlit.

## Project Overview

Customer churn occurs when customers stop using a company's products or services. This project demonstrates how Machine Learning can help identify customers who may be likely to leave.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle

## Machine Learning Model

This project uses a Logistic Regression model to predict customer churn.

## Project Structure

- `app.py` — Streamlit application
- `main.py` — Model training and project logic
- `logistic_regression_model.pkl` — Saved Machine Learning model
- `data/` — Dataset files
- `requirements.txt` — Python dependencies

## Installation and Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/Abdallah-eng152/CustomerChurnAI.git
   cd CustomerChurnAI
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows:

   ```bash
   .venv\Scripts\activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Streamlit application:

   ```bash
   streamlit run app.py
   ```

To apply Machine Learning to a practical business problem and build an interactive application for customer churn prediction.
